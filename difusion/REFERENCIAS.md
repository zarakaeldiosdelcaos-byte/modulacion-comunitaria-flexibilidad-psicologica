# Referencias y fuentes documentales

## 1. Criterio de inclusión

Este archivo documenta las fuentes que sustentan el proyecto y su trazabilidad documental.

El estudio de **Modulación comunitaria y flexibilidad psicológica en la recuperación de adicciones: un estudio de mediación secuencial** se deriva de un proyecto de investigación más amplio, del cual proceden bases de datos, instrumentos, scripts, análisis previos y documentos conceptuales.

Por esta razón, este repositorio integra las fuentes directamente relacionadas con el análisis actual junto con aquellos materiales del proyecto amplio que permiten documentar la procedencia de sus variables, instrumentos y antecedentes.

### Reglas de documentación

* Se priorizan las fuentes conservadas en el corpus documental del proyecto.
* También se registran referencias mencionadas explícitamente en documentos que forman parte de ese corpus.
* No se completan datos bibliográficos ausentes mediante inferencias.
* No se incorporan referencias únicamente por asociación temática.
* Las fuentes procedentes de otras líneas de investigación se mantienen identificadas como antecedentes o fuentes relacionadas.
* La ausencia de una ficha bibliográfica completa se señala de forma explícita, sin reconstruirla artificialmente.

---

# 2. Bibliografía específica del proyecto

El documento principal del proyecto contiene el título, resumen y palabras clave, pero no una bibliografía consolidada.

Por ello, este repositorio no presenta una lista de referencias como si hubiera formado parte originalmente del resumen o del documento de proyecto.

En su lugar, la documentación bibliográfica se organiza a partir de las fuentes efectivamente conservadas en el proyecto más amplio:

```text
FUENTES DIRECTAMENTE RELACIONADAS
        ↓
INSTRUMENTOS Y MATERIALES
        ↓
ANTECEDENTES TEÓRICOS Y METODOLÓGICOS
        ↓
REFERENCIAS MENCIONADAS EN DOCUMENTOS DEL CORPUS
```

Esta organización permite conservar la **trazabilidad documental del análisis** sin atribuir al proyecto referencias que no estén respaldadas por las fuentes disponibles.

# 6. Estados documentales

Para mantener una distinción clara entre una obra conservada, una referencia registrada y una referencia mencionada de manera parcial, se utilizan las siguientes categorías:

| Estado                                      | Significado                                                                                                                                                                      |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Fuente documental**                       | El archivo forma parte del corpus y puede consultarse directamente.                                                                                                              |
| **Referencia registrada en el corpus**      | El documento local conserva una referencia bibliográfica con información suficiente para identificarla en el propio corpus.                                                      |
| **Mención documental**                      | La obra aparece mencionada en un documento, pero el corpus no conserva necesariamente una ficha bibliográfica completa.                                                          |
| **Referencia mencionada; ficha incompleta** | La referencia forma parte de la documentación del proyecto, pero no se dispone de información suficiente para reconstruir una ficha completa sin recurrir a fuentes adicionales. |

Estas categorías describen el **estado documental dentro del repositorio** y no constituyen una clasificación sobre la calidad o relevancia de las obras citadas.

# 7. Criterio para futuras incorporaciones

Una referencia podrá incorporarse posteriormente cuando exista nueva evidencia documental que permita identificarla de manera inequívoca.

En ese caso, deberá conservarse junto con su procedencia correspondiente.

No se incorporarán referencias únicamente por:

* memoria de los investigadores;
* semejanza temática;
* asociación con un instrumento;
* identificación aproximada por autor y año;
* necesidad de completar una bibliografía formal.

La incorporación de una nueva referencia deberá poder responder a:

```text
¿De qué fuente documental procede?
```

---

# 8. Relación con el proyecto principal

El proyecto de mediación secuencial forma parte de un **proyecto de investigación más amplio**.

En consecuencia, las fuentes documentales conservadas en este repositorio cumplen funciones diferentes:

* algunas sustentan directamente el análisis actual;
* otras documentan los instrumentos empleados;
* otras corresponden a antecedentes de líneas previas de investigación;
* otras forman parte del marco conceptual y metodológico del proyecto amplio.

Por ello, la presencia de una referencia en este archivo **no implica automáticamente que haya sido utilizada como referencia directa del modelo estadístico principal**.

La función de este documento es preservar la relación entre el proyecto actual y el corpus documental del que se deriva.

---

# 9. Cierre documental

La política de referencias de este repositorio prioriza:

```text
TRAZABILIDAD
+
PROCEDENCIA
+
CONTEXTO
+
PRECISIÓN DOCUMENTAL
```

El objetivo no es reconstruir retrospectivamente una bibliografía ideal, sino dejar registro de las fuentes que efectivamente forman parte del corpus y de su relación con el proyecto actual.

Cuando una referencia no puede documentarse de forma completa con las fuentes disponibles, se conserva su estado documental sin completar información por inferencia.
